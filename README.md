# はやれき

栽培履歴の記録と、JA提出様式への書き写しを自動化する仕組みです。
スマホで日々の作業を記録し、月末に一度コマンドを実行すると、部会の提出様式（Excel）に月ごとの施肥と防除が書き込まれます。

飛騨のトマト農家が自分の畑で1シーズン運用しながら作りました。

## できること

- スマホから施肥・防除・作業を記録する（複数区画をまとめて選べる）
- 防除の入力中に希釈倍率をその場で判定する（濃すぎ・薄すぎ）
- 月末に検算する：希釈倍率、農薬の使用回数、区画別のカウント、化学窒素の上限、月別のカリ÷窒素比
- JA提出様式に書き戻す：施肥は月ごとの資材別合計、防除は同じ日の同じ薬剤を1行にまとめる

## 中身

| ファイル | 役割 |
|---|---|
| `apps_script/Code.gs` `apps_script/index.html` | 入力アプリ（Google Apps Script のウェブアプリ） |
| `hayareki.py` | 検算と、提出様式への書き戻し |
| `config.example.json` | 区画名や様式の列位置の設定例 |

## 入力アプリの準備（初回だけ）

1. Google スプレッドシートを新しく作る
2. 「拡張機能 → Apps Script」を開き、`Code.gs` の中身を貼る。HTML ファイルを追加して名前を `index` にし、`index.html` の中身を貼る
3. 関数 `setup` を選んで実行する（権限の許可を求められる）。シート「記録」「区画」「肥料」「農薬」「作業」ができる
4. 「区画」「肥料」「農薬」「作業」の見本を自分の内容に書き換える
5. 「デプロイ → 新しいデプロイ → ウェブアプリ」。実行するユーザーは自分、アクセスは自分のみ
6. 表示された URL をスマホで開き、ホーム画面に追加する

マスターの見方：

- 区画：`面積a` と `ハウス数`
- 肥料：成分は％で入れる（10% なら 10）。液肥は `比重` に 1ℓあたりの重さ（kg）を入れる
- 農薬：`使用回数上限` が 0 なら回数制限なし。`カウント` は総使用回数に数える薬剤なら 1、展着剤などは 0。`計算方法` は希釈するなら「希釈」、粒剤などは「直」

## 入力のきまり

- 1行1件で溜まります。区画を3つ選んで保存すると3行になります
- 防除の使用量と水量は、タンク全体の量を入れます（区画ごとに割らない）
- 混用は1回の保存で3剤まで入れられます
- 施肥の量は kg と ℓ から選べます。ℓ で入れた量は「肥料」シートの `比重`（1ℓあたりのkg）を掛けて kg に直します。15ℓ入りで正味20kgの液肥なら 1.33。空欄は 1 として扱います
- 施肥には潅水時間（分）も残せます。肥料を入れずに水だけ流した日は、資材で「水のみ」を選んで潅水時間だけ入れます（「肥料」シートに `水のみ` の行を作っておく）

## 月末の手順

1. スプレッドシートを「ファイル → ダウンロード → Microsoft Excel」で保存する（例：`記録.xlsx`）
2. 初回だけ：`config.example.json` を `config.json` にコピーし、区画名と様式の列位置を自分の様式に合わせる
3. 検算する

   ```
   python hayareki.py check --db 記録.xlsx
   ```

4. 提出様式に書き戻す

   ```
   python hayareki.py export --db 記録.xlsx --template 先月の提出用.xlsx --out 今月の提出用.xlsx
   ```

5. Excel で開いて確かめてから提出する

`--template` には先月提出したファイルを渡してください。防除は、様式にまだ書かれていない「日付×薬剤」だけを追記するので、手で直した行はそのまま残ります。施肥は月ごとの合計を書き直します。記録の側を正として扱うので、数字を直すときは記録の方を直してください。

## 設定（config.json）

- `plots_alias`：複数区画のまとめ名（例：「東側」＝第1〜第3）
- `fertilizer_apportion`：同じ量で入力し、小さい区画には実際は少なく撒いている場合の按分。`basis_houses` 棟の区画を基準に、ハウス数に比例させる。使わないなら `null`
- `names_to_ja`：入力側の呼び名と、様式のリストでの正式名が違うときの対応。全角半角・大文字小文字の違いだけなら書かなくてよい
- `ja_form`：様式のシート名と列・行の位置

## AppSheet 版の DB からも使えます

`--db` に AppSheet 版の DB スプレッドシートを xlsx で保存したものを渡すと、自動で判別して読みます。区画の通称は `plots_alias` に書いてください。AppSheet 版の農薬マスターには「カウント」の列がないので、分類が展着剤のものと、使用回数上限が 0 のものを数えない扱いにしています（`count_rule`）。

## AppSheet 版との違い

| | AppSheet 版 | このリポジトリ |
|---|---|---|
| 費用 | 利用者が増えると座席課金 | 無料 |
| 電波のない場所 | 入力しておけば後で同期される | 保存できない（圏内で入力する） |
| 他の人への配布 | アプリのコピーが必要 | コードを渡せば同じものが作れる |
| 入力中の倍率判定 | 作り込み次第 | 標準で表示 |

## 必要なもの

- Python 3.9 以上
- `pip install -r requirements.txt`

## 注意

- JA 提出様式はこのリポジトリに含めていません。各自の部会で配られたものを使ってください
- 検算は記録の自己点検の補助です。農薬のラベルや最新の登録内容の確認に代わるものではありません
- `config.json` と xlsx には自分の区画名や記録が入るので、公開リポジトリには上げないでください（`.gitignore` で除外しています）
